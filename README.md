# Multilingual Sign Language Translation (clean release)

PyTorch code for joint continuous **sign language recognition** (gloss, CTC) and **sign-to-text translation**, based on SignJoey / Camgoz et al. (CVPR 2020), with extensions for:

- English silver-standard supervision (PHOENIX-2014-T release-v3)
- Unified German–English training with language tags
- Language-specific translation heads (`DE+EN-v4`)
- Stage-2 cascade: English pivot → NLLB → French / Arabic

**Reproduce the paper pipeline:** see [`REPRODUCE.md`](REPRODUCE.md).

## Clone

```bash
git clone git@github.com:i0607/SLTR---multilanguage.git
cd SLTR---multilanguage
git checkout clean-release
```

## Quick start

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Place PHOENIX-2014-T features under data/ (see data/README.md)
# Then follow REPRODUCE.md
```

For the Stage-2 cascade (NLLB / COMET):

```bash
python3 -m venv venv-stage2
source venv-stage2/bin/activate
pip install -r requirements-stage2.txt
```

## Repository layout

| Path | Contents |
|------|----------|
| `signjoey/` | Training / decoding library |
| `configs/` | YAML configs for all reported models |
| `scripts/` | Dataset builders + evaluation utilities |
| `experiments/de_en_v*` | Unified DE+EN training scripts |
| `experiments/stage2_multilingual/` | NLLB cascade + paper evaluation |
| `data/` | Empty placeholder (features not shipped) |
| `REPRODUCE.md` | Step-by-step experiment commands |

## Config → paper model map

| Config | Paper name |
|--------|------------|
| `configs/sign_improved_v4.yaml` | Model-ODE (German) |
| `configs/sign_improved_v4_english.yaml` | Model-OEN (English) |
| `configs/sign_improved_v5.yaml` | Model-A (ablation) |
| `configs/sign_de_en_v2.yaml` | DE+EN-v2 |
| `configs/sign_de_en_v3_finetune.yaml` | DE+EN-v3 |
| `configs/sign_de_en_v4_langhead_finetune.yaml` | DE+EN-v4 |

## What is **not** included

- Pre-extracted visual features / pickles (license + size)
- Checkpoints (`.ckpt`), `train.log`, decode hypotheses
- Stage-2 prediction files and COMET JSON outputs
- Thesis / paper draft Word–PDF files
- Local virtualenvs

These are regenerated by following `REPRODUCE.md`.
